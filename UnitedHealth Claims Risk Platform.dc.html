UnitedHealth Group
Healthcare Claims Risk Prediction & Cost Optimization Platform
Project 01
Project Objective

Developed an advanced machine learning platform to identify high-risk members, predict future healthcare costs, and support care-management teams in prioritizing interventions.

Key Responsibilities
  • Processed large-scale healthcare claims, pharmacy, provider, eligibility, and demographic datasets using Python, SQL, pandas, and PySpark.
  • Built member-level features such as prior claims cost, hospital visits, chronic conditions, medication history, provider utilization, and cost trends.
  • Developed classification and regression models using XGBoost, LightGBM, CatBoost, Random Forest, and PyTorch.
  • Used Optuna for automated hyperparameter tuning and improved model selection through stratified cross-validation.
  • Addressed class imbalance using class weighting, SMOTE, threshold optimization, and cost-sensitive learning.
  • Applied SHAP to explain model predictions and identify the main factors contributing to member risk.
  • Evaluated models using ROC-AUC, PR-AUC, recall, precision, F1-score, calibration, MAE, and RMSE.
  • Tracked experiments, model versions, parameters, and performance metrics using MLflow.
  • Deployed real-time risk-scoring services using FastAPI, Docker, and cloud-based endpoints.
  • Implemented model monitoring using Evidently, Prometheus, and Grafana to detect data drift, prediction drift, and performance degradation.
  • Collaborated with healthcare analytics, care-management, engineering, and business teams to translate model outputs into actionable member-risk segments.
